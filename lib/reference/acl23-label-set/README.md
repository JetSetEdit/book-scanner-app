# acl23 label set (reference)

Institutional trigger-warning label taxonomy from [acl23-trigger-warning-assignment](https://github.com/MattiWe/acl23-trigger-warning-assignment) (Matti Wiegmann, MIT). Pulled from `acl23_trigger_warning_assignment/resources/label-set/` for reference and optional mapping to our taxonomy.

## Files

| File | Description |
|------|-------------|
| `tw-coarse.json` | 7 coarse categories: discrimination, aggression, abuse, pregnancy, medical, mental-health, sexual-content |
| `tw-fine-closed.json` | 29 fine labels (closed set used in their dataset) |
| `tw-fine-open.json` | 36 fine labels (includes "other-*" variants) |
| `map-fine-to-coarse.json` | Maps each fine label to its coarse category |
