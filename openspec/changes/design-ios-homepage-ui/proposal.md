# Change: Design iOS Homepage UI/UX and Color System

## Why

The iOS app needs a cohesive design system with a beautiful, book-focused aesthetic that matches the Subtext brand. The homepage is the first impression users have of the app, so it should be visually appealing, clearly communicate the app's purpose, and provide intuitive navigation. A well-designed color palette and typography system will create consistency across all screens.

## What Changes

- **Homepage Design**: Create a visually striking homepage with brand identity, search functionality, and clear value proposition
- **Color System**: Define a cohesive color palette (background, primary, secondary, highlight) that evokes books and reading
- **Typography**: Establish typography system using serif fonts for brand identity and readability
- **Navigation Structure**: Design bottom tab navigation for main app sections (Home, Scan, Bookshelf, Settings)
- **Search Interface**: Design search bar that's prominent and accessible from homepage
- **Visual Hierarchy**: Establish clear visual hierarchy with logo, tagline, and descriptive text

## Impact

- **Affected specs**: New iOS UI design capability
- **Affected code**: 
  - Homepage view (ContentView or HomeView)
  - Color system definitions
  - Typography constants
  - Navigation structure
- **Breaking changes**: None (this is design/UI only)
- **Design system**: Establishes foundation for all future iOS screens
