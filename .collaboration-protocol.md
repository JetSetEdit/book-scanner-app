# AI Collaboration Protocol

## Purpose
This file helps coordinate work between multiple AI assistants (Antigravity, Cursor, etc.) to avoid conflicts and respect each other's work.

## Status Files

### `.antigravity-working.md`
- Created when Antigravity is actively working on files
- Lists files Antigravity is currently modifying
- Other AIs should NOT modify these files until cleared

### `.cursor-working.md`
- Created when Cursor is actively working on files
- Lists files Cursor is currently modifying
- Other AIs should NOT modify these files until cleared

## File Markers

### In-File Markers
Add comments at the top of files being worked on:
```typescript
// @antigravity-working - Do not modify
// @cursor-working - Do not modify
```

### Directory Markers
- `antigravity-wip/` - Antigravity's work-in-progress files
- `cursor-wip/` - Cursor's work-in-progress files

## Workflow

1. **Before Starting Work:**
   - Check `.antigravity-working.md` and `.cursor-working.md`
   - Check for `@antigravity-working` or `@cursor-working` comments
   - If files are marked, wait or ask for coordination

2. **When Starting Work:**
   - Create/update your status file (e.g., `.cursor-working.md`)
   - List all files you're modifying
   - Add in-file markers if needed

3. **When Completing Work:**
   - Remove your status file
   - Remove in-file markers
   - Commit changes

4. **If Conflict Detected:**
   - Check git status
   - Review recent commits
   - Coordinate via this file or git comments

## Priority Rules

1. **Antigravity has priority** on files marked in `.antigravity-working.md`
2. **Cursor has priority** on files marked in `.cursor-working.md`
3. **First to mark wins** - if no markers, first AI to start work owns it
4. **Read-only is safe** - reading files is always OK, modifying requires checking

## Communication

- Use git commit messages to communicate: `[ANTIGRAVITY] Working on X`
- Use this file's comments section for coordination
- Tag files with `@antigravity` or `@cursor` in commit messages

## Emergency Override

If urgent fix needed on locked file:
1. Check git log for recent activity
2. Make minimal, safe changes
3. Add comment: `// @override: [reason]`
4. Update status file with override note
