# Project Handover Document: Subtext Book Scanner

## Project Overview
Subtext is a book scanning application designed to help parents and readers identify content warnings, age ratings, and suitability for books. It uses AI-driven analysis (Gemini) to provide detailed breakdowns of themes like violence, language, and mature content.

## Current Status
- **Production URL**: [subtextscanner.com.au](https://subtextscanner.com.au) — *See [docs/WHICH_SITE.md](docs/WHICH_SITE.md) for “which site is which” (canonical vs preview vs legacy Vercel).*
- **Access Control**: Currently in beta. Australian users have direct access based on IP. International users (US, GB, CA, NZ) access via a "Welcome" gate at `/welcome` with limited quotas.
- **Core Features**:
  - **Scanning**: Barcode/ISBN scanning with AI analysis.
  - **Collection**: A searchable library of scanned books.
  - **SSS Filter**: Subtext Suitability Scale for filtering books by age and content sensitivity.
  - **Audit Logging**: Comprehensive logging of AI analysis and metadata status.

## Recent Achievements (Feb 2026)
- **Data Reliability**: Implemented fallback to Open Library Works API when Google Books descriptions are missing, significantly reducing "thin metadata" issues.
- **Pipeline Robustness**: Fixed bugs in the scanning pipeline (`scan-service.ts`) to ensure accurate logging of AI analysis failures and metadata warnings.
- **User Interface**: Added a responsive sidebar filter for the bookshelf, allowing users to filter by age rating and warning severity.
- **Persona**: Restored and stabilized "Clawbert" (the AI assistant) with updated identity files (`IDENTITY.md`, `SOUL.md`).

## Signup & Access Flow
The "live production" experience for a new user depends on their location:
1. **Australian Users**: Automatically granted access. No signup or gate required.
2. **International Users**: Redirected to `/welcome`. 
   - They select their country and "Join Beta".
   - If the country's quota is not full, they are granted access.
   - This sets a `subtext_access_granted` cookie and records the entry in the `access_grants` table.
3. **VIPs**: Can bypass the gate via a VIP cookie (`subtext_vip`).
